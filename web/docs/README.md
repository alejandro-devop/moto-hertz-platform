## 📋 Resumen del Proyecto

Este proyecto implementa un sitio web moderno para Yamaha con:

- ⚡ **Next.js 14** con App Router
- 🎨 **SASS** para estilos avanzados
- 🚀 **Optimizaciones de rendimiento** (Lighthouse 90+)
- 📱 **Diseño totalmente responsive**
- 🔄 **React Query** para manejo de estado del servidor
- 🌊 **Efectos parallax** personalizados
- 🖼️ **Optimización de imágenes** con formatos modernos
- 🔧 **Cliente HTTP singleton** con TypeScript

## 🏗️ Arquitectura

```
src/
├── app/              # App Router de Next.js
├── components/       # Componentes reutilizables
├── hooks/           # Hooks personalizados
├── providers/       # Context providers
├── styles/          # Estilos SASS globales
└── utils/           # Utilidades y helpers
```

## 🛠️ Stack Tecnológico

- **Framework**: Next.js 14
- **Lenguaje**: TypeScript
- **Estilos**: SASS + CSS Modules
- **Estado**: React Query
- **Formato de código**: Biome
- **Imágenes**: Optimizadas con AVIF/WebP
- **Deploy**: Vercel/Netlify
